교사용 결과 확인

응답 파일을 가져온 뒤 회차·학급별 결과를 확인하세요. 학생에게는 학생용 파일과 검사 설정 파일만 배포하세요.

교사용 잠금 해제

공용 기기에서는 교사가 준비하고 감독해 주세요. 이 파일은 정식 심리검사나 의료적 진단 도구가 아닙니다. 원척도·사용 허가·대상 연령·채점 기준은 별도 확인이 필요합니다.

암호는 4~200자이며 숫자 4자리도 가능합니다. 짧은 암호는 추측하기 쉬워 긴 암호를 권장합니다. 암호를 잊으면 복구할 수 없습니다.

암호화 백업을 복원합니다

개선판의 암호화 JSON 파일을 선택한 후, 해당 백업을 만들 때 사용한 암호로 잠금을 해제하세요. 복원 시 현재 데이터 전체가 교체됩니다. 기존 데이터를 먼저 백업하세요.

검사 결과를 확인합니다

검사 준비와 응답 수집

학생에게는 학생용 HTML과 여기서 만든 검사 설정 JSON만 전달하세요. 교사용 HTML·암호·암호화 보관함 백업은 전달하지 마세요.

설정 파일에는 공개 암호화 키와 회차·학급만 들어 있습니다. 기존 보관함을 삭제하거나 새로 만들면 이전 설정으로 받은 응답을 열 수 없으므로 암호화 백업을 보관하세요.

총점 범위는 25~100점입니다. 이 점수는 기존 파일의 채점 규칙을 적용한 참고값입니다. 전국 규준, 백분위, 진단, 상담 필요성 판정이 아닙니다. 하위영역의 명칭·구성 타당성도 검증되지 않았습니다. 서로 다른 학년·회차를 합쳐 해석하지 마세요.

5분 동안 조작이 없거나 다른 탭·앱으로 이동하면 잠깁니다. CSV와 인쇄물은 암호화되지 않습니다. CSV에는 학생 정보와 25개 문항 응답이 포함됩니다. 전체 CSV 백업은 필터와 관계없이 모든 응답을 저장하며, 암호화 JSON 백업도 계속 사용할 수 있습니다.

표준편차는 표시된 자료의 기술통계이며 n으로 나눕니다. 동일 회차·학년반·번호가 겹치는 응답은 중복 확인 대상으로 표시하지만, 자동으로 삭제하거나 통계에서 제외하지 않습니다.

엑셀용 CSV 백업을 가져옵니다

이 수정판에서 저장한 CSV를 지원합니다. 현재 보관함에 병합하며, 같은 ID와 내용은 건너뜁니다. 동일 ID의 내용이 다르면 전체 가져오기를 중단합니다. 점수 열은 신뢰하지 않고 25개 응답에서 다시 계산합니다. 엑셀에서 수정 후 저장할 때는 CSV UTF-8 형식을 선택하고, 열 제목과 ID를 유지하세요.

원본 프로그램의 백업을 가져옵니다

원본의 평문 JSON 배열만 지원합니다. 25개 응답이 있는 행만 허용하며 점수는 다시 계산합니다. 날짜 정보가 없어 가져오기 회차를 지정해야 합니다. 같은 ID와 내용은 건너뛰고, 같은 ID에 다른 내용이 있으면 전체 가져오기를 중단합니다.

데이터 보호를 위해 실행을 중단했습니다.

저장값은 자동 삭제하지 않습니다. 브라우저의 사이트 데이터를 지우지 말고 담당자에게 문의하세요. 이미 내려받은 백업은 보관해 주세요.

이 프로그램은 별도 서버에 연결하지 않습니다. 암호화는 잠긴 상태의 저장 데이터 노출을 줄이지만, 악성 브라우저 확장·기기 관리자·개발자 도구·변조된 HTML로부터 완전한 보호를 제공하지는 않습니다. 실제 다수 학생 운영에는 서버 기반 인증·접근권한·감사기록과 개인정보 처리 체계가 필요합니다.
